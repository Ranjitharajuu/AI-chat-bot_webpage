# 🤖 AI Chatbot Web App

This is an AI-powered chatbot web application that allows users to interact with an AI assistant using text, voice, and image inputs.

---

## 🚀 Features

- 💬 Chat with AI (text input)
- 🎤 Voice input support
- 🔊 Optional voice response
- 🖼️ Image upload support
- ✨ Typing animation
- 💾 Chat history saved locally

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- AI: OpenAI API
